lexeme_form_metadata.yaml
=========================

`View code on Github <https://github.com/scribe-org/Scribe-Data/tree/main/src/scribe_data/resources/metadata/lexeme_form_metadata.yaml>`_

This file contains definitions of the lexeme forms used in Scribe-Data. This ordered YAML allows for the consistent generation of query forms and mapping forms to their respective string representations.

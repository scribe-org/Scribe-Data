# [Data Contracts](https://github.com/scribe-org/Scribe-Data/tree/main/src/scribe_data/resources/data_contracts)

This directory contains the Scribe-Data data contracts. These contracts are used both within Scribe-Data to derive queries for data as well as in the client applications to determine how data is presented to the user in the UI. Please see [GitHub:scribe-org/Organization/DATA_CONTRACTS.md](https://github.com/scribe-org/Organization/blob/main/DATA_CONTRACTS.md) for more information.
